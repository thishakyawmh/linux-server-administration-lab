# Linux Package Management

## Objective

Learn how to manage software packages in Ubuntu using APT.

## Commands Practiced

| Command | Purpose |
|---|---|
| `sudo apt update` | Update package information |
| `sudo apt upgrade` | Upgrade installed packages |
| `apt search` | Search for packages |
| `apt show` | Display package information |
| `sudo apt install` | Install packages |
| `apt list --installed` | List installed packages |
| `sudo apt remove` | Remove packages |
| `sudo apt purge` | Remove packages and configuration files |

## Practical Exercise

- Updated Ubuntu package information.
- Searched for Nginx.
- Inspected package information.
- Installed and tested htop.

## What I Learned

- How Ubuntu manages software packages.
- How to install and remove software using APT.
- How to search and inspect package information.
- Difference between apt remove and apt purge.
